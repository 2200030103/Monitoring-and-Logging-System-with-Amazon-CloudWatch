
This project showcases a scalable monitoring and logging framework using AWS CloudWatch. It provides real-time insights into the performance, security, and operational health of AWS EC2 instances and other cloud resources.

## 🔧 Features
- Monitors CPU, memory, and network metrics
- Custom CloudWatch Dashboards
- Alarm and SNS-based alerting
- Secure log storage using CloudWatch Logs and IAM
- Real-time analysis with Logs Insights
- Integration with CloudTrail for auditing

## 🛠️ Technologies Used
- Amazon Web Services (EC2, CloudWatch, SNS, IAM, CloudTrail)
- CloudWatch Logs & Metrics
- Log Insights
